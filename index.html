  • Simple Library FastAPI یک API ساده برای مدیریت کتابخانه با FastAPI: دریافت، افزودن، ویرایش و حذف کتاب. فعلاً داده‌ها بدون دیتابیس در یک لیست پایتون نگه‌داری می‌شوند.
